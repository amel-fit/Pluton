# Pluton

**Pluton** is a roguelike dungeon-exploration game made in Unity. Fight through procedurally challenging rooms full of skeleton enemies, collect power-ups, survive encounters, and clear the dungeon.

---

## 🕹️ Quick Info
- **Title:** Pluton  
- **Genre:** Roguelike / Dungeon Crawler  
- **Engine:** Unity (C#)  
- **Authors:** Vedad Trako, Amel Husika

---

## 🎮 Description
Pluton combines fast-paced melee combat with room-based dungeon exploration. Each run sends the player through a series of rooms with enemies, traps, and rewards. The objective is to clear rooms, gather coins and power-ups, and survive as long as possible.

---

## ✨ Features
- Melee **combat** vs skeleton and humanoid enemies  
- Multi-room **dungeon exploration**  
- Collectible **coins** and **power-ups**  
- **Ability** system (example: *Thorns*)  
- Simple UI showing health, ability state, and coins  
- Room hazards (spikes, traps) and loot piles

---

## ▶️ How to Run (for development)
1. Clone or download the repository.  
2. Open the project folder in **Unity (recommended version: 2020.3+ or your project's version)**.  
3. Go to **File → Build Settings** and set the appropriate platform (Windows / macOS / Linux).  
4. Press **Play** in the Unity Editor to run the game.  
5. (Optional) Create a build in **Build Settings → Build** to produce a playable executable.

---

## 🕹 Controls
- **Move:** WASD
- **Attack:** J 
- **Dash:** Shift
- **Interact / Buy:** E  
- **Use ability:** Right mouse button / Q  
- **Pause:** Esc
